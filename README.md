# harrybot2
A program for making Reactbot-likes.

To use repository version: 
1. Download repo and open in Visual Studio Code (or other program with a terminal and npm support)
2. Run "npm install" in terminal to install dependencies
3. Run "npm run start" to run initial start-up functions
4. Add a base video (i.e. the video that will loop if the bot is not speaking) to the videos folder, and the videos of the bot speaking to the videos/clips folder
5. Run "npm run start" again
6. Press F7 to see the bot speak one of the lines you have ingested
